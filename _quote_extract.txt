004| 一、报价说明
005| 1. 报价原则
006| 应贵方（北京铭芯启睿科技有限公司）对大模型统一接入与成本治理需求，结合长期合作愿景，本报价采用「储值 + 按量计费」的轻量合作模式：客户在 ApiHub 平台储值，平台为客户开通企业管理账户，实际费用根据模型用量计算，平台按月提供对账单并开具发票。
007| • 储值不用不扣、按需消耗：储值余额仅在实际调用发生时按 token 计量扣减，不用不扣、不清零。
008| • 按量计价、无最低消费：除重点档、战略档按约定周期消费承诺执行外，不设最低消费与保底。
009| • 一账户多模型：一个企业账户即可调用平台已开通的全部模型，各模型按自身单价分别计量。
010| • 折扣随量级自动提升：储值额度或月度消费达到更高量级，自动适用更优阶梯折扣（详见第三章）。
011| • 零建设周期：无开发、无部署，账户开通后当日即可完成首通调用。
012| 2. 服务内容说明
013| 本报价为大模型调用服务 + 企业管理账户服务，涵盖：
014| • 企业管理账户开通（独立租户、管理后台、成员与角色权限）
015| • API 令牌管理（多令牌、额度上限、来源限制、即时吊销）与模型白名单
016| • 全平台模型调用（Claude / OpenAI 等，清单详见第三章）
017| • 实时用量计量与余额管理（额度告警、限额、超额停服保护）
018| • 日 / 月用量对账单与消费明细导出（含分模型、分令牌、分成员维度）
019| • 模型鉴真审计与《模型鉴真审计报告》（详见第五章）
020| • 数据出海安全、财务结算与审计合规保障（详见第六章）
021| • 技术支持：帮助文档 + 客服工单 + 专属对接群
022| 3. 计价方式
023| • 计价单位：元 / 百万 tokens（RMB per 1M tokens）。
024| • 本报价为含税价，税率 6%，按实际消费金额开具增值税发票。
025| • 计费维度：输入 tokens、缓存命中 tokens、输出 tokens 三类分别计量后汇总。
026| • 价格链条：原厂挂牌价 →（模型级折扣）→ ApiHub 平台售价 →（阶梯折扣）→ 客户成交价。
