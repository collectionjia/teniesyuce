# 投注服务（`services/betting/`）

**实施优先级：④** · 端口：**9103**

详见 [项目模块与实施优先级 · P4](./项目模块与实施优先级.md#p4--优先级-4投注服务betting) · [模块边界与限制](./模块边界与限制.md)

---

## 职责

读 **规则服务** 的 matched 集，对 Polymarket **买入**；金额 strictly 用 matched 中的 `amountUsd`。

- prematch matched → 2h 节奏 scan
- inplay matched → 30s 节奏 scan

**不做**：采集、规则计算、止损卖出。

---

## 执行需求

1. **REQ-B-01** 新建 `services/betting/`，端口 9103。
2. **REQ-B-02** `POST /internal/betting/scan`：body 可带 `bucket`（prematch/inplay）；等价现 `bet.scan` buy。
3. **REQ-B-03** 只处理 `tennis:rules:matched:*`；无数据 → `{ matched: 0, placed: 0 }`。
4. **REQ-B-04** `betting.enabled === false` → `skipped`。
5. **REQ-B-05** 迁移：`tennisBettingEngine.js` buy、`polymarketTrade.js`、`tennisTrade.js`；支持 `simulate`。
6. **REQ-B-06** 订单落 MySQL/Redis：`eventId`、`bucket`、`groupId`、`amountUsd`、`side`、`txHash`、`status`。
7. **REQ-B-07** 同场同组 **去重**：已有 open 订单不再买。
8. **REQ-B-08** prematch 2h / inplay 30s（由 scheduler 触发）。
9. **REQ-B-09** `GET /internal/betting/orders/open` 供 stop-loss 消费。
10. **REQ-B-10** `GET /health`；scan metrics：`scanned`、`placed`、`skipped`、`errors[]`。
11. **REQ-B-11** **默认配置**：沿用现网 `betting.*`（默认 `enabled=false`，`amountUsd=1`）。
12. **REQ-B-12** **可修改配置**：后台改金额/账号/组开关 → MySQL → Redis。

---

## 数据流

```
读：tennis:rules:matched:prematch|inplay
读：tennis:engines:config.betting（开关、simulate）
写：MySQL 订单（status=open）
```
