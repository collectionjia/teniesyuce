# 网站测试用例

测试环境默认：`http://46.250.163.215:9018/`  
本地：前端 Vite + 后端 API（见 README）。

约定：

| 符号 | 含义 |
|------|------|
| P0 | 发版必测 |
| P1 | 核心回归 |
| P2 | 扩展 / 边界 |

通过标准：步骤可复现；期望结果与实际一致；无控制台致命错误；关键接口返回合理。

## 3. 盘前 / 盘中 / 盘后列表

| ID | 优先级 | 步骤 | 期望 |
|----|--------|------|------|
| T-01 | P0 | 盘前有数据时打开 | 仅未开始场次；无整块「筛选」面板 |
| T-02 | P0 | 盘中无数据 | 文案为「暂无数据」（无「请先采集…」长提示） |
| T-03 | P0 | 盘中有数据 | 仅进行中场次；可刷新 |
| T-04 | P0 | 盘后有数据 | 已结束场次；顶部有盈亏统计条 |
| T-05 | P1 | 条件引擎开 + 产品挂了列表条件组 | 列表被服务端条件过滤（比未挂载时更少或不同） |
| T-06 | P1 | 条件引擎关或桶关 | 列表不过滤（或按设计跳过） |
| T-07 | P1 | 产品未配置 `condition_select` | 列表不过滤 |
| T-08 | P1 | 盘后统计：合计 / 盘前 / 盘中 | 比率与 PnL 数字合理；有投注条件组时出现「前·组名 / 中·组名」拆分 |
| T-09 | P1 | 盘后：无真实成交、有条件组 | 规则旁显示「纸」（纸面回测） |
| T-10 | P2 | 虚拟数据源（采集引擎切虚拟 txt） | 盘前/盘中/盘后能出模拟场次 |
| T-11 | P2 | 批量投注权限用户 | 盘前/盘中可见批量栏；盘后无买入批量 |
| T-12 | P2 | 打开单场详情 | 排名 / 比分 / 外链等字段正常 |

## 5. 条件引擎

| ID | 优先级 | 步骤 | 期望 |
|----|--------|------|------|
| C-01 | P0 | 总开关开/关并保存 | 刷新后状态保持 |
| C-02 | P0 | 盘前 / 盘中 / 盘后分桶开关 | 独立生效 |
| C-03 | P0 | 新建条件组、改名称、改字段、保存 | Redis/配置持久化；刷新可见 |
| C-04 | P0 | 删除条件组（含删到 0 组） | 可删空；不再被 normalize 还原 |
| C-05 | P0 | 组内字段：巡回 / PM / 现差 / 排差 / 强现开区间 | UI 为「强现」+ `<x<`，标签无多余 `>` |
| C-06 | P0 | 盘中：现差分档 | 可选不限 / 分档达标 |
| C-07 | P0 | 盘中/盘后：赢首盘 | 勾选后参与过滤 |
| C-08 | P0 | 赢首盘 + 排除首盘 + 局分 `7:5` | 首盘为 7:5（或 5:7）的场次被排除；`7-5` 等价 |
| C-09 | P1 | 组间无 AND/OR | 条件页不可配组间关系；文案指向产品管理 |
| C-10 | P2 | 强现开区间 `0 < x < 10` | 仅强者现排名在开区间内通过 |
